Problems Viewing These Videos?

NOTE: Most videos on this site are in Microsoft Windows Media (.WMV) format. If you are using an older version of Windows Media Player, you may need to install the latest Windows Media codecs to view these videos: a codec package installer is available at the Windows Media site.

For videos that use DiVX encoding, you'll need the free decoder here. A free player is included as well, although the videos should play in your regular video player once the decoder is installed.

If the video does not launch correctly in your browser, you may need to right-click the video and select "Save Link Target As..." to save it to your hard drive first.

If you're a Linux user, be sure to check out the Xine player, which can play back Windows WMV video files.
